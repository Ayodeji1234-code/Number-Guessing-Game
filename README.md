# Number Guessing Game

## Description

The Number Guessing Game is a simple command-line Python application where the computer randomly generates a number between 1 and 100, and the player attempts to guess it. The program provides feedback after each guess, indicating whether the guess is too high or too low, until the correct number is guessed or the maximum number of attempts is reached.

## Features

* Random number generation between 1 and 100
* Multiple attempts to guess the number
* Feedback for each guess ("Too High" or "Too Low")
* Input validation for invalid entries
* Maximum attempt limit
* Option to play again after each game

## Technologies Used
* Python 3
* Random Module

## How to Run

1. Ensure Python is installed on your computer.
2. Download or clone this project.
3. Open a terminal in the project directory.
4. Run the program using:
py number_guessing_game.py
or
python number_guessing_game.py
